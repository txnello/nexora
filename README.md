# NEXORA

**A smarter way to decide what to work on next.**

NEXORA is a free Windows desktop app for organizing tasks and seeing what needs your attention first. Its automatic score ranks open tasks using priority, due dates, reminders and age, so urgent work is easier to spot.

> **Completely free. No subscription and no paid features.** If NEXORA is useful to you, you can optionally support its development with a donation.

## Download and installation

To build the installer from this repository and install NEXORA:

1. Download the project from GitHub (**Code → Download ZIP**) and extract it.
2. Run `Build\UpdateInstaller.bat` and approve the administrator prompt. The script does everything for you: it installs Inno Setup 6 via `winget` if it is missing, runs the tests, compiles `Nexora.exe`, generates `Release\Nexora-Setup.exe` and launches it.
3. Follow the setup wizard.

NEXORA supports Windows 10 and Windows 11. To update, repeat the steps from the updated source and run `Build\UpdateInstaller.bat` again.

## Why NEXORA?

- **Know what to focus on:** an automatic, configurable score ranks tasks by priority, deadline, reminders and age.
- **Make it yours:** customize statuses, priority levels, owners, date format, colors and scoring weights.
- **Keep work organized:** use search, filters, task history, reminders and optional links on tasks.
- **Stay in control of your data:** tasks and settings are stored locally on your PC. You can choose a different data folder and create or restore backups.
- **For individuals and teams:** use it for personal work or internal business task management.

NEXORA does not require an account or an internet connection for its task-management features. If you choose a cloud-synchronized folder, that synchronization is provided by your own cloud service; close NEXORA on other devices before using the same data folder to avoid conflicting edits.

# NEXORA (Italiano)

**Un modo più semplice per capire a quale task dedicarsi.**

NEXORA è un’applicazione desktop gratuita per Windows che aiuta a organizzare i task e a individuare quelli che richiedono attenzione per primi. Il suo score automatico ordina i task aperti considerando priorità, scadenze, solleciti e anzianità.

> **Completamente gratuita. Nessun abbonamento e nessuna funzione a pagamento.** Se NEXORA ti è utile, puoi sostenere facoltativamente il suo sviluppo con una donazione.

## Download e installazione

Per compilare l’installer da questa repository e installare NEXORA:

1. Scarica il progetto da GitHub (**Code → Download ZIP**) ed estrailo.
2. Esegui `Build\UpdateInstaller.bat` e conferma la richiesta di privilegi amministratore. Lo script fa tutto da solo: installa Inno Setup 6 tramite `winget` se manca, esegue i test, compila `Nexora.exe`, genera `Release\Nexora-Setup.exe` e lo avvia.
3. Segui la procedura guidata.

NEXORA supporta Windows 10 e Windows 11. Per aggiornare, ripeti i passaggi dalla sorgente aggiornata ed esegui di nuovo `Build\UpdateInstaller.bat`.

## Perché NEXORA?

- **Scopri su cosa concentrarti:** uno score automatico e personalizzabile ordina i task in base a priorità, scadenza, solleciti e anzianità.
- **Adattala al tuo modo di lavorare:** personalizza stati, livelli di priorità, referenti, formato data, colori e pesi dello score.
- **Tieni tutto organizzato:** ricerca, filtri, cronologia, solleciti e link facoltativi nei task.
- **I dati restano sotto il tuo controllo:** task e impostazioni vengono salvati localmente sul PC. Puoi scegliere un’altra cartella dati e creare o ripristinare backup.
- **Per singoli e team:** usala per il lavoro personale o per la gestione interna dei task aziendali.

NEXORA non richiede un account né una connessione Internet per le funzioni di gestione dei task. Se scegli una cartella sincronizzata tramite cloud, la sincronizzazione è fornita dal servizio cloud scelto da te; chiudi NEXORA sugli altri dispositivi prima di usare la stessa cartella, per evitare modifiche in conflitto.
